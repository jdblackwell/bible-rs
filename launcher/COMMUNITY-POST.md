# Community announcement — draft, not posted

**Bible for Omalauncher — based on bible-rs (Preview 1)**

I've been adapting bible-rs for reading inside Omalauncher's Arch environment.
Credit for the original project goes to **Micky and the bible-rs contributors**;
this work started from **ForrestKnight's fork**. Omalauncher adaptation and
device testing: **Javahax**.

The preview adds phone touch controls, settings that fit the screen, note and
bookmark layouts, and an optional reading/search widget. It runs as an ARM64
Linux app inside Omalauncher, not as a standalone APK. The original licenses
and full project history are retained, and general improvements are intended
to be offered upstream for review.

Original project: https://github.com/michaelshimeles/bible-rs
